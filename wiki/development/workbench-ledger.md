# Workbench delivery ledger

Updated: 2026-11-09

## Goal

Deliver a movie-revision workbench that absorbs and extends an earlier prototype editor's scene-graph, editable-keyframe and composition workflow. A person can import a rough movie, extract it into editable storyboard shots, revise shot order, images and timing quickly, reuse visual styles across a series of screens, and give Claude precise changes to execute. Projects must be creatable, saved, closed, reopened and switched in the app. The player must handle stills, video and audio across intercut scenes.

## Constraints

- Work only in `/Users/ryders/Developer/GitHub/nb-storyboard-workbench` on `workbench`. Preserve the main and `nb-storyboard-final` trees. No push or history rewrite under the current handoff. Do not commit without an explicit request.
- Keep every document edit in the project ops/undo path. Preserve dirty work, source files, current delivery candidates and source-bound test evidence.
- Verify changed behavior with focused tests and the actual UI when an isolated browser is available. Report UI acceptance separately from build and API checks.

## Key decisions

- Numbered images import as one shot, one panel per image in natural numeric order, with equal frame spacing and copied project sources. Entry points: CLI and workbench.
- The player shows one scene at a time and uses hard cuts to intercut scenes whose events overlap.
- A placement's default time comes from the latest end of attached content such as video, voice-over and storyboard panels. If voice-over outlasts video, hold its last frame and warn in the info panel about the unmatched duration. Explicit trim/slot edits remain editorial overrides.
- The primary use case is revising rough Claude-made movies. MP4 import copies the original, samples a representative frame per range, supports manual marks, and can suggest visual cuts for review. Interval sampling remains useful for continuous recordings with no hard cuts. Guarded source-boundary rolling is now implemented for adjacent untouched imported shots.
- Still unresolved: whether off-screen scenes have exact advancing story clocks; how audio continues over a hard cut.
- The prototype editor's functionality belongs in this NB Storyboard workbench; the prototype is source/reference, not the destination. Extend its scene graph, editable keyframes and screen composition with reusable style templates applied to a series of editable screens. Keep each screen's content and timing independent. A flattened MP4 or still cannot be restyled without editable source or new overlay layers.
